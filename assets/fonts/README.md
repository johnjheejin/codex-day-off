# Afterglow display face

`newsreader-display-latin.woff2` is the unmodified Latin WOFF2 served by Google Fonts for Newsreader, optical size 72, weight 400, normal style (21,704 bytes).

- Typeface designer: [Production Type — Newsreader](https://productiontype.com/font/newsreader)
- Upstream: [productiontype/Newsreader](https://github.com/productiontype/Newsreader)
- Source CSS: <https://fonts.googleapis.com/css2?family=Newsreader:opsz,wght@72,400&display=swap>
- File: <https://fonts.gstatic.com/s/newsreader/v26/cY9qfjOCX1hbuyalUrK49dLac06G1ZGsZBt4ByzBDXXD9JVF438weI_wC-ZFHDWwgUii.woff2>
- License: [SIL Open Font License 1.1](./NEWSREADER-OFL.txt), obtained from the [Google Fonts distribution](https://github.com/google/fonts/blob/main/ofl/newsreader/OFL.txt)
- Retrieved: 2026-09-06

The app loads this local file, with no Google Fonts network request at runtime. `font-display: swap` and the Georgia/Times/serif fallback keep the heading visible if the file is unavailable. Include this directory and license when distributing the static app.
