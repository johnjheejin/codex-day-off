# 나머지 장면과 공유 화면 개선

사용자의 “나머지 장면이나 공유하는 화면에도 비슷한 개념으로 검토해서 개선하자”는 요청에 따라 첫 화면의 디자인 방향을 확장했다. `DESIGN.md`를 기준으로 읽고 이번 요청에 맞춰 제목·결과·공유 규칙을 갱신했다. 추가 스킬과 하위 에이전트는 사용하지 않았다.

## 디자인 판단과 변경

기존 결과는 큰 숫자와 통계, 반복된 버튼이 작품보다 먼저 읽혔다. 공유 안내와 일시정지는 첫 화면과 별도의 기본 UI처럼 보였다. 이는 화면을 직접 보고 내린 디자인 판단이며 사용자 조사 결과로 주장하지 않는다.

- **결과:** 작은 장면 이름, Newsreader 제목 `The sky / is yours.`, 실제 PNG 미리보기로 위계를 정리했다. 수집이 없으면 `Room to / breathe.`로 표시한다. 수집 개수만으로 추정하던 분위기·속도 설명은 제거하고 실제 개수와 색 수만 작은 하단 기록으로 남겼다.
- **공유:** `Share image`와 `Download PNG`를 먼저 배치하고 LinkedIn·X·Telegram·KakaoTalk은 구분선이 있는 텍스트 행으로 정리했다. 표시 순서와 키보드 순서가 같다. 파일 크기 대신 실제 이미지 해상도를 표시하며 문구와 링크는 펼쳐서 읽고 복사할 수 있다.
- **모바일:** 제목 옆에 원래 비율의 작은 작품을 두고 공유를 바로 아래에 배치했다. 큰 데스크톱 썸네일을 그대로 축소하지 않는다. 세로 태블릿은 더 넓은 작품 미리보기와 전체 폭 공유 영역을 사용한다.
- **일시정지·공유 안내:** Night/Paper의 배경·본문·구분선 색을 따르고 세리프 제목과 짧은 설명을 사용한다. 공유 안내는 실제 작품과 세 단계의 구체적인 행동을 보여 준다.
- **플레이·PNG:** `Nothing due`와 짧은 수집 문구에 세리프를 연결하고 타이머·숫자는 읽기 쉬운 별도 서체로 낮췄다. PNG에는 원래 작품 구도와 테두리 HUD를 유지하며 하단 문구를 `A moment, kept.`로 정리했다. 해시태그는 이미지 대신 공유 문구에 남겼다.

새 그래픽 효과나 지속 렌더링 루프는 추가하지 않았다. PNG는 기존 로컬 서체 로딩을 최대 400ms 기다린 뒤 대체 서체를 사용하며, 기다리는 사이 다른 장면이나 세션으로 바뀌면 오래된 생성을 무시한다.

## 공유 동작 교정

- 파일 공유 지원 여부를 확인하고 네이티브 공유에는 실제 PNG를 포함한다. 지원하지 않으면 자동 다운로드·복사 전에 안내를 보여 준다. 공유 취소는 실패 알림을 띄우지 않는다.
- 소셜 앱별 안내에 PNG를 수동으로 첨부해야 할 수 있음을 명시했다. 카카오톡은 가능하면 기기 공유 화면에서 선택하며, 파일 공유가 불가능하면 수동 안내로 이어진다.
- 클립보드 API와 대체 복사가 모두 실패하면 선택 가능한 문구를 열어 두고 실패 사실을 표시한다. 모달 안에서 대체 복사가 작동하도록 임시 입력도 모달 내부에 둔다.
- 새 탭이 차단되면 안내를 유지하고 불필요한 다운로드를 시작하지 않는다. 안내창을 열면 제목에 포커스가 오고 닫으면 원래 버튼으로 돌아간다.

검증에서는 네이티브 공유·클립보드·외부 창을 모의 대상으로 대체했다. 실제 게시나 메시지를 보내지 않았으며 각 소셜 앱의 로그인 이후 흐름까지 검증한 것은 아니다. 공유 링크는 기존 홈페이지 주소이며 작품별 복원 링크는 아직 구현하지 않았다.

## 검증 결과

`npm test`에서 런타임 guard, 정책·동작 단위 검사 13개와 브라우저 시나리오 24개가 통과했다. 총 37개다. 새 공유 검사 5개는 파일 공유 미지원, PNG 포함과 취소, 복사 실패, 앱별 안내, 새 탭 차단을 다룬다.

마지막 캡처에서 Paper 전환 직후 이전 Night 미리보기를 볼 수 있는 준비 상태 문제를 찾아 교정했다. 결과의 `View sky`를 즉시 비활성화하고 새 PNG 생성 후 활성화한다. 반응형·장면 전환 관련 기존 검사 5개를 다시 통과했고 공유 검사 5개도 재실행했다. 복사 실패 검사는 320×568에서 안내창을 스크롤해 복사하고 `Not now`로 닫은 뒤 원래 버튼에 포커스가 돌아오는 것까지 확인한다.

| 화면 | 결과 가로 넘침 | 기본 공유 버튼 하단 | 안내창 |
| --- | --- | --- | --- |
| 1440×900 | 없음 | 약 393px | 전체 내용 표시 |
| 768×1024 | 없음 | 약 571px | 전체 내용 표시 |
| 390×844 | 없음 | 약 441px | 전체 내용 표시 |
| 320×568 | 없음 | 약 419px | 세로 스크롤, 가로 넘침 없음 |

Night/Paper 모두 위 범위에서 캡처했다. 결과·공유 안내·일시정지·플레이와 실제 다운로드 PNG를 확인했고, 결과에서 렌더링이 멈추는 기존 검사도 통과했다. `git diff --check`도 통과했다. 모바일 자동 검증은 화면·입력·픽셀 예산의 근사이며 S24 실기기의 온도나 장시간 GPU 부하를 증명하지 않는다.
