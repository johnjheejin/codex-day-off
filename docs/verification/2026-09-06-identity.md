# 2026-09-06 — 하늘에서 온 서명

기존 해·수평선 심벌과 굵은 산세리프 이름을 교체했다. 한 점에서 비대칭으로 펼쳐지는 세 꽃잎과 떨어진 작은 점을 심벌로 쓰고, Newsreader Display의 소문자 윤곽을 직접 간격 조정한 워드마크와 짝지었다. 실제 경험의 꽃 선과 랜딩의 세리프 제목이 로고까지 이어진다.

## 적용 범위

- 웹 헤더와 원본 PNG는 동일 SVG 경로를 사용한다. PNG는 헤더 경로를 `Path2D`로 읽어 그리므로 로고를 위한 추가 이미지·폰트 로딩이 없다. 홈 버튼의 이름과 이동·확인 동작은 유지한다.
- 모바일에서는 심벌 26px, 워드마크 86px로 표시하고 설명을 숨긴다. 버튼은 44px 이상이며 320px 화면에서도 소리·장면 버튼과 겹치지 않는다.
- 파비콘, 180px 홈 화면 아이콘, 1200×630 링크 미리보기와 README 표지를 제공한다. 미리보기의 꽃은 제품과 같은 `flowerVertices`로 그렸다. 링크는 공개 경험을 나타내며 개인 작품 복원 링크를 의미하지 않는다.
- 원본은 `assets/brand/identity.json`, 배포 가능한 SVG/PNG와 사용 안내는 [브랜드 자산](../../assets/brand/README.md)에 있다. 글자 윤곽의 Newsreader 출처·OFL 라이선스를 남긴다.
- 일반 빌드에서 SVG와 인라인 헤더를 함께 갱신하며, CI가 소스와 체크인된 자산의 일치를 확인한다. 명시적 배포 목록은 기존 8개에 브랜드 7개를 더한 15개다. 로고를 계속 움직이는 렌더링 루프는 추가하지 않았다.

## README

현재 경험을 먼저 소개하도록 다시 구성했다. 새 표지와 실제 데스크톱·모바일 캡처, 라이브 하늘·Touch/Turn·공유·최근 결과 복원, 소리와 발열 관련 제한, 개발 명령과 코드 지도, 브랜드 자산, 자동 배포, 제작 일지를 연결했다. 지난 화면과 모델 이야기의 상세 기록은 별도 일지·감사 문서에 보존한다.

## 확인

단위 21개·브라우저 32개를 통과했다. 기존 반응형 검사에 로고의 44px 조작 높이와 우측 버튼 비중첩 조건을 더했다. 실제 30초 종료, 두 렌더러, PNG 저장, 모달·공유, 모바일 터치와 랜딩 복원이 포함된다.

1440×900, 390×844, 320×568에서 두 장면과 실제 PNG를 눈으로 확인했다.
