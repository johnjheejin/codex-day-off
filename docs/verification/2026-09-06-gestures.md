# 손길이 남는 Afterglow

- 날짜: 2026-09-06
- 범위: Astra 데모 조사에서 제안한 첫 구현 묶음
- 상태: 로컬 구현. 공개 배포·기존 ZIP 갱신·실기기 열 검증은 수행하지 않음
- 추가 스킬과 하위 에이전트를 사용하지 않음

## 바뀐 경험

꽃 형태를 무작위로 정하던 부분을 실제 움직임에 연결했다. 화면에서 보이는 포커스의 방향이 꽃의 방향으로 남고, 이동 속도가 길쭉함을, 곡률이 꽃잎 수와 말림을, 짧은 멈춤이 풍성함을 정한다. 속도가 수집 범위나 보상량을 늘리지는 않는다. 색과 꽃의 위치는 기존 수집 장면을 유지한다.

가까운 꽃은 포커스 쪽으로 살짝 기울었다 돌아온다. 터치 장치는 가장 가까운 4송이, 데스크톱은 6송이까지 입력을 받는다. 반경 밖으로 나간 반응은 빠르게 감쇠한다. 전체 배열을 매 프레임 복제·정렬하지 않고 작은 후보 목록을 유지한다. 새로운 geometry나 드로 콜을 이 효과 때문에 추가하지 않는다.

30초가 끝나면 수집과 포인터를 멈추고 마지막 꽃이 펴지는 하늘을 1.6초 보여 준다. `Keep this sky` 또는 Escape로 바로 결과를 열 수 있다. reduced motion에서는 즉시 결과로 이동한다. 숨겨진 페이지와 BFCache 복귀에서는 숨겨진 시간을 플레이·마무리 시간에 포함하지 않는다. 결과 화면은 계속 정지해 있다.

WebGL, Canvas 대체 화면과 PNG가 같은 꽃 곡선과 XYZ 회전식을 사용한다. GPU 장애 때 원래 곡선·방향·형태를 이어서 그린다. 장애 직후 캔버스 크기를 복구하면서 잠깐 빈 화면이 생기던 경우도 같은 작업 안에서 즉시 다시 그리도록 교정했다. 작은 동작 번들까지 실패하면 기존 Canvas 방식으로 30초 플레이와 저장을 계속 제공한다.

## 구현과 예산

- `src/garden-motion.js`: 시간 단위 입력 추적, 가까운 꽃 반응, 공유 곡선과 pose, Canvas 투영.
- `src/afterglow-garden.js`: 정적 HTML에서 동작하는 작은 진입점. minified 약 3.4KB.
- `src/afterglow-three.js`: 공유 곡선을 geometry로 재사용하고 꽃의 scale·rotation만 갱신. 번들은 약 531.2KB.
- `index.html`: 입력·수집·마무리·수명주기를 연결. 숨김/일시정지/화면 크기 변경 후 오래된 입력 위치로 잘못된 커브를 만들지 않는다.
- 해상도 변경만 일어날 때는 입력 추적을 초기화하지 않는다. 60fps 시작과 측정에 따른 90/120fps 승격, 해상도 우선 조절, 모바일 150만 픽셀 상한을 유지한다.
- 배포 시 `index.html`, `assets/afterglow-three.js`, `assets/afterglow-garden.js`를 함께 포함해야 한다.

## 검증

정적 guard와 단위 검사 13개, 브라우저 시나리오 19개를 확인했다. 전체 실행에서 단위 검사 13개와 브라우저 18개가 통과했고, 새 모바일 검사의 가상 시계가 첫 렌더 전에 관찰하던 테스트 순서 문제를 수정한 뒤 해당 검사도 통과했다. 실제 모바일 앱의 실패가 아니라 테스트의 첫 프레임 대기 누락이었다.

- 같은 곡선 입력을 30·60·120Hz로 샘플링했을 때 꽃잎 수가 같고 형태 값 차이가 작음을 검증했다.
- 직선·커브·역방향 커브·정지의 다른 형태, 입력 재개, 반응 수 상한과 감쇠, reduced motion 고정을 확인했다.
- Canvas 좌표와 Three.js 회전 행렬을 비교해 같은 geometry·pose가 같은 꽃을 투영함을 확인했다.
- 실제 커서 수집으로 서로 다른 꽃 형태와 주변 꽃의 기울기를 관찰했다. GPU context loss 뒤에는 색 있는 Canvas 픽셀이 남아 있음을 검사하고 화면을 확인했다.
- 정상 30초 플레이, 종료 후 추가 수집 중지, 마무리 장면의 숨김/재개, 조기 종료, 접근성 포커스, 결과 렌더링 정지를 확인했다.
- 기존 모바일/터치 데스크톱 모드 픽셀 상한, 미리보기·공유 6종 접근, 회전 뒤 세로 PNG, 소리, 일시정지, resize burst와 리소스 해제 검사를 유지했다.
- 390×844 터치 에뮬레이션에서 손길로 만든 Paper Sky를 780×1688 PNG로 저장했다. 총 1,316,640픽셀로 모바일 상한 이내다.

실제 커서로 플레이한 로컬 Chrome Beta 측정 지점은 60fps, CPU 작업 p90 약 0.9ms, 최근 GPU 샘플 약 0.7ms였다. 같은 전체 실행의 다른 측정 지점에서는 GPU 4.6ms였다. 이는 일부 로컬 관찰이며 분포나 실기기 발열 안정성을 입증하지 않는다. 가상 시계를 쓰는 종료/모바일 검사의 FPS 값은 성능 근거로 사용하지 않는다.
