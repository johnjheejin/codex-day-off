# 2026-09-06 — 결과를 떠나지 않는 하늘

완료 화면을 라이브 하늘 자체로 바꿨다. `Still yours.`와 별도의 결과 카드가 차지하던 자리를 비우고, 아래에 실제 생각·색 수와 Touch / Turn / Reset / Share만 둔다. Share를 누르면 원본 PNG와 여섯 가지 전달 방법이 모달로 열린다. 닫으면 같은 하늘과 시점으로 돌아온다.

## 종료와 이동

- 30초가 끝나면 꽃 그룹이 2.8초 동안 한 번 돌아 얕은 깊이를 보여주고 정면으로 돌아온다. 원래 배치에서 자연스럽게 라이브 보기 여백으로 이동한다. Keep this sky 또는 Escape로 바로 건너뛸 수 있다.
- 종료 연출과 손길 반응은 최대 60fps다. 연출이 끝나고 입력이 없으면 렌더링을 멈춘다. 숨겨진 탭은 연출 시간을 소비하지 않으며, 모션 줄이기는 자동 회전을 생략한다. 렌더링 예약이 중복되지 않도록 종료 진입과 최초 미리보기 예약도 정리했다.
- Touch는 정면으로 돌아와 꽃을 스치고, Turn은 드래그나 방향키로 시점을 돌린다. WebGL과 Canvas가 같은 변환을 쓴다. 원본 객체와 PNG에는 탐색 회전을 적용하지 않는다.
- 로고는 랜딩을 연다. 진행 중에는 시간·소리·렌더링을 멈추고 돌아갈지 묻는다. 취소나 Escape는 같은 시점부터 이어간다.
- 최근 완료 작품 하나와 PNG를 메모리에 보존한다. 새 휴식을 시작했다가 중단해도 이전 완료 작품은 남는다. 랜딩의 Return to your sky는 화면 크기나 랜딩의 장면을 바꾼 뒤에도 작품의 장면과 원본 이미지를 복원한다.

## 검증

단위 20개와 브라우저 32개를 통과했다. 마지막 모바일 배치와 렌더링 예약 조정 뒤 관련 시나리오도 다시 통과했다. 실제 30초 종료, 자동 회전의 진행과 정면 복귀, 숨김 정지, 입력 후 휴지 상태, 공유창의 초점과 시점 보존, 로고 확인 취소, 새 휴식 중단 후 이전 PNG 복원을 검사한다.

320×568, 390×844, 태블릿, 일반 데스크톱과 4K를 포함한다. 공유창은 네이티브 모달로 배경 조작을 막고, 작은 화면에서 끝까지 스크롤해도 닫기 버튼에 접근할 수 있다. PNG 직접 전달·다운로드·소셜 안내·클립보드 실패와 팝업 차단 검사를 유지했다. 외부 게시와 메시지 전송은 모의 대상으로 검사했다.

## 범위

최근 작품은 현재 페이지 메모리에만 남는다. 새로고침 후 복원, 영구 보관함과 작품별 라이브 공유 링크는 이번 범위에 포함하지 않는다. 실제 Galaxy S24의 장시간 온도·전력 측정도 수행하지 않았다. GPU 실패는 Canvas로, 두 번들 모두 실패한 경우에는 정적 하늘과 PNG 공유로 이어진다.

공개 배포와 환경별 검증 결과는 [배포 운영 기록](../deployment.md)을 따른다.
